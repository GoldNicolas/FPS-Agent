## Outcome
The policy learned the task. The training-time return rose from −2.97 to +14.87 and levelled off at about +15 after about 15 batches. The episode length fell from 357 to 65 steps. Headless `-Infer` playback of the final snapshots (job 151708, 120 s) reached **100.0%** of targets with avgReturn **+10.25**. That is the same as the `-Scripted` upper bound (job 151709). The training numbers sit about +5 above that because of a reward bookkeeping bug in training mode (C-004). Not promoted anywhere: this is a pipeline spike, not a curriculum stage.

## Play it back (LOCAL)
1. Download: `gh release download run-spikeA-20261111-151705 -D <folder>`, then check the files against `SHA256SUMS`.
2. Run a game built from `cccd809` (or the same Spike A code) with `-Stage=SpikeA -Infer -ResumeFrom=<folder>`.
   - `-Infer` needs `encoder.bin`, `policy.bin` and `decoder.bin`.
   - `critic.bin` is only for resuming training.
   - A missing file exits with code 2.

Expect agents to walk straight to each target. The game log should show about `reached=100%` and `avgReturn` about +10.25.
