## Outcome
**The agent learned S0 up to the hardest level in one 300-batch job, but missed the promotion gate by 3 points: 67.0% against 70%.**
- **Learning:** it first learned to clear one bot around batch 85 (window 200 of 690; about 2.3 windows per batch). The ramp then climbed from 0 to 1.0 over about 190 batches, with training clear rates of 78–90%.
- **Promotion trigger:** mean `level=` ≥ 0.9 for the last 10 windows in every game, reached in job 152039 (end level 0.998).
- **Promotion test:** `-Eval -EvalEpisodes=200 -StartDifficulty=1 -Seed=1000 -Arenas=32` cleared **134 of 200 (67.0%)**, so `passed: false`.
  - All 66 failures were timeouts; there were no deaths, since S0 bots don't shoot.
  - Kills per episode: 3.96 of 5.
  - The scripted reference cleared 100% (3.5 s average).
- **Next:** the continuation job 152055 trains 300 more batches at level 1, then the same gate is re-run.

## Problems / observations
1. **No failures.** All 4 games exited 0 and the trainer exited 0, with no errors in the game logs. The only trainer output after the run is the cosmetic `_worker` shutdown traceback (smoke report, observation 4).
2. **Log volume is fine:** about 2 MB per game for 300 batches, about 16,000 `Resetting Agents` lines per game once episodes de-synchronized. The script gzips the logs at the end of each job; `-LogCmds` isn't needed.
3. **26–39 Learning Agents warnings per game:** `PPOTrainer_0: Agent with id N has completed episode and will be reset but has not generated any experience.`
   - Each comes one decision after that agent's previous reset, so the new episode ended on its first decision. That's about 0.2% of episodes.
   - The game resets the held action at every episode start (`UCombatArena::StartEpisode`).
   - So these are most likely genuine first-decision clears: the single bot of a low-level or review episode is roughly in front at spawn and dies to the first action within 4 ticks. Game 1's first stats window shows exactly that with an untrained policy: `clearTime=0.1s acc=100% hs=100%`.
   - Learning Agents drops such one-step episodes from the replay buffer. Harmless at 0.2%; no request filed.
4. **The promotion trigger fired before the policy met the gate.** "Mean level ≥ 0.9 for 10 windows" is reached as soon as the ramp tops out, which happens at a training clear rate (with review episodes) above 70%. At level 1 the non-review clear rate is lower. The chain logic therefore stopped at the trigger, and the continuation was submitted by hand.
