**Goal:** Original tactical-shooter blockout maps, with elevation, defined as JSON tile grids. They are validated and generated in Python and built at runtime in C++ (in the editor and headless on Cradle). The deliverables are one hand-designed original map (`map01`) and a pool of validated procedural variants.

**Architecture:**
- **One text format, two consumers.**
  - Python (`tools/mapgen`) owns validation, generation and PNG previews.
  - C++ (`FMapSpec`, `FPSArena::BuildMap`) parses a spec and spawns merged gray blocks plus a sky.
- **Packaging.** Specs ship inside the game build (`Content/MapSpecs`, staged as UFS).
- **Game mode.** `AArenaGameMode` replaces `ARangeGameMode`. It builds either the range or a map, chosen by `-Map=` or a project setting.

**Tech stack:**
- Python 3.11 (conda-forge: numpy, matplotlib, pytest)
- UE 5.7 C++ (adds the `Json` module)
- Unreal-MCP for play-in-editor (PIE) checks and screenshots

**Spec:** `README.md` → Maps, and `CLAUDE.md` hard rule 5 (original maps only).

## Global Constraints
- **Originality.** Layouts follow genre structure (spawns, 2–3 sites, mid, lanes, chokes) and are **original**. They must not be traced from, or modeled on, any existing game's map. No Riot names.
- **Units.** cm in C++ and JSON numbers. Python works in tiles and converts with `tile_cm` and `level_cm`.
- **Coordinates.**
  - Row 0 is **north = +X** (the top of the text). Column 0 is **west**, and +Y is east.
  - Tile (r, c) center in world space: `X = (rows-1-r+0.5)*tile_cm`, `Y = (c+0.5)*tile_cm`.
  - Floor top: `Z = level*level_cm` (+0.5 level for ramps).
- **Everything still works under `-nullrhi`.** Lights and sky are spawned only when `FApp::CanEverRender()`.
- **Tests.**
  - C++ test names start with `FPSAgent.Map.`.
  - Python tests live in `tools/mapgen/tests`.
  - Cast UE double math types to float in `TestEqual` calls.
- **Workflow.**
  - Build with `tools/build.ps1` (editor closed). C++ tests run with `tools/run_tests.ps1`.
  - Python tests run with `conda run -n fps-agent python -m pytest tools/mapgen -q`.
  - Commits use the `[local]` prefix plus the Co-Authored-By trailer, then `git pull --rebase && git push`.

## Map format v1 (`Content/MapSpecs/<name>.json`)
```json
{
  "format": 1,
  "name": "map01",
  "tile_cm": 400,
  "level_cm": 100,
  "wall_cm": 600,
  "tiles":   ["#####", "#...#", "..."],
  "heights": ["00000", "01110", "..."],
  "zones":   [".....", ".aa..", "..."]
}
```
- **Grid shape:** three grids with identical dimensions (rows of equal length), at least 8×8.

- **`tiles` characters:**

  | Char | Meaning |
  |---|---|
  | `.` | Floor |
  | `#` | Wall (from the floor up to `wall_cm`; blocks movement, sight and bullets) |
  | `l` | Low cover, 120 cm (standing players see and shoot over it; a crouched head hides behind it) |
  | `h` | High cover, 250 cm (blocks standing sight) |
  | `x` | Void (no floor, out of bounds) |
  | `^` `v` `>` `<` | Ramp rising one level toward north / south / east / west |

  Walkable tiles are `.` and the ramps.

- **`heights`:** digits `0`–`9`, the floor level of each tile. For a ramp, it is the level of its **low** end. Ignored for `#` and `x`.
- **`zones`:**

  | Char | Meaning |
  |---|---|
  | `.` | No zone |
  | `a` | Attacker spawn |
  | `d` | Defender spawn |
  | `A` `B` `C` | Sites (A and B required, C optional) |
  | `m` | Mid |

### Movement graph (4-neighbour, used by validation)
| Move from u to v | Allowed when |
|---|---|
| floor → floor | `level(v) <= level(u)`: same level, or a drop of any height |
| into a ramp at level h rising toward d | from its low neighbour (opposite d, level h) or its high neighbour (toward d, level h+1) |
| out of a ramp | to its low neighbour, its high neighbour, or a side neighbour whose level ≤ h (a drop) |

Ramps can only be entered along their axis.

### Line of sight (2.5D)
- **Eye height:** 158 cm above the floor top, for standing beans.
- **Method:** march the straight segment between two tile-center eye points in steps of a quarter tile, skipping the start and end tiles.
- **Blocking:** a sample is blocked if the segment height at that point is ≤ the obstacle top there.

| Tile | Obstacle top |
|---|---|
| `#` | +∞ |
| `h` | floor + 250 |
| `l` | floor + 120 |
| `.` | floor |
| ramp | floor + `level_cm`/2 |
| `x` | −∞ |

### Validation rules (`mapgen.validate.validate(spec) -> list[str]`; an empty list means valid)
1. `dims`: three equal-size grids, at least 8×8.
2. `chars`: only legal characters.
3. `border`: every border tile is `#` or `x`.
4. `ramps`: the low neighbour is walkable at level h, and the high neighbour is walkable at level h+1.
5. `zones`:
   - `a` and `d` each cover ≥ 4 floor tiles.
   - `A` and `B` each cover ≥ 9 walkable tiles. `C` is optional with the same minimum.
   - `m` covers ≥ 9 walkable tiles.
   - Spawn zones only on `.` tiles.
6. `connectivity`: all walkable tiles form a **single strongly connected component** (no dead ends after a drop).
7. `spawn_los`: no line of sight between any `a` tile and any `d` tile.
8. `sightlines`:
   - Sample 4000 random walkable-pair line-of-sight checks within 50 m (seed 0), and keep the visible pairs.
   - Distance bands: close < 10 m, mid 10–25 m, long 25–50 m.
   - Targets (tunable constants in `validate.py`): close ≥ 0.30, mid ≥ 0.25, long between 0.03 and 0.30.

```python
from mapgen.spec import MapSpec, tile_center_world
from mapgen.grid import walkable, floor_top_cm, has_los, scc_count, neighbors_graph

def tiny(tiles, heights=None, zones=None):
    rows = len(tiles)
    heights = heights or ["0" * len(tiles[0])] * rows
    zones = zones or ["." * len(tiles[0])] * rows
    return MapSpec(name="t", tile_cm=400, level_cm=100, wall_cm=600, tiles=tiles, heights=heights, zones=zones)

def test_tile_center_orientation():
    s = tiny(["####", "#..#", "#..#", "####"])
    x, y, z = tile_center_world(s, 0, 0)          # row 0 = north = largest X
    assert (x, y, z) == (1400.0, 200.0, 0.0)
    x2, y2, _ = tile_center_world(s, 3, 3)
    assert (x2, y2) == (200.0, 1400.0)

def test_floor_top_ramp_half_level():
    s = tiny(["#####", "#.^.#", "#####"], ["00000", "00010", "00000"])
    assert floor_top_cm(s, 1, 2) == 50.0            # ramp low level 0 -> +0.5 level
    assert floor_top_cm(s, 1, 3) == 100.0

def test_walls_block_los_low_cover_does_not():
    open_ = tiny(["#######", "#.....#", "#######"])
    wall = tiny(["#######", "#..#..#", "#######"])
    low = tiny(["#######", "#..l..#", "#######"])
    high = tiny(["#######", "#..h..#", "#######"])
    assert has_los(open_, (1, 1), (1, 5))
    assert not has_los(wall, (1, 1), (1, 5))
    assert has_los(low, (1, 1), (1, 5))
    assert not has_los(high, (1, 1), (1, 5))

def test_platform_edge_blocks_low_eye():
    # a 2 m platform between two level-0 tiles hides them from each other
    s = tiny(["#######", "#.....#", "#######"], ["0000000", "0022200", "0000000"])
    assert not has_los(s, (1, 1), (1, 5))

def test_drop_is_one_way_ramp_is_two_way():
    drop = tiny(["#####", "#...#", "#####"], ["00000", "01000", "00000"])
    g = neighbors_graph(drop)
    assert (1, 2) in g[(1, 1)] and (1, 1) not in g[(1, 2)]    # down yes, up no
    assert scc_count(drop) == 2
    ramp = tiny(["######", "#.>..#", "######"], ["000000", "000110", "000000"])
    assert scc_count(ramp) == 1
```

def errors_with(spec, key):
    return [e for e in validate(spec, check_sightlines=False) if e.startswith(key)]

def test_toy_is_valid():
    assert validate(base(), check_sightlines=False) == []

def test_open_border():
    s = base(); s.tiles[0] = "#.############"
    assert errors_with(s, "border")

def test_bad_ramp():
    s = base(); s.heights[5] = "00100000000000"   # ramp low end now level 1 -> high side must be 2
    assert errors_with(s, "ramps")

def test_dead_end_drop():
    s = base(); s.tiles[5] = "#............#"     # remove the ramp: platform becomes drop-only
    assert errors_with(s, "connectivity")

def test_missing_site_b():
    s = base(); s.zones = [z.replace("B", ".") for z in s.zones]
    assert errors_with(s, "zones")

def test_spawns_see_each_other():
    s = base()
    for r in (3, 4, 9, 10):                       # open a 2-wide gap straight through both wall bars
        s.tiles[r] = s.tiles[r][:6] + ".." + s.tiles[r][8:]
    assert errors_with(s, "spawn_los")
